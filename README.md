# از AI بپرس (askai)

نسخهٔ ChatGPTی «بذار من برات گوگل کنم».
وقتی کسی به‌جای پرسیدن از هوش مصنوعی از شما می‌پرسد، سؤالش را اینجا تایپ می‌کنید، یک لینک کوتاه می‌گیرید و برایش می‌فرستید.
او که لینک را باز کند، یک صفحهٔ کاملاً شبیه chatgpt.com می‌بیند: نشانگر موس خودش روی کادر متن کلیک می‌کند، سؤال تایپ می‌شود، دکمهٔ ارسال زده می‌شود و در نهایت به `https://chatgpt.com/?prompt=...` منتقل می‌شود.

## ویژگی‌ها

- طراحی تاریک (پیش‌فرض) و راست‌به‌چپ، شبیه صفحهٔ اصلی ChatGPT (نوار کناری، نوار بالا، composer گرد، چیپ‌های پیشنهادی)
- کاملاً ریسپانسیو (موبایل، تبلت، دسکتاپ)
- فاویکان لوگوی OpenAI
- انیمیشن fade در ورود عناصر + انیمیشن موس و تایپ
- کوتاه‌کنندهٔ لینک با کد تصادفی یا کد دلخواه
- ضدّاسپم ساده: honeypot + امضای زمان فرم + محدودیت سرعت
- ذخیره‌سازی خودکار: SQLite و در صورت نبود، فایل JSON (مناسب هاست اشتراکی)
- بدون نیاز به Composer یا دیتابیس MySQL

## نصب روی هاست اشتراکی

1. تمام فایل‌ها را در `public_html` (یا هر زیرپوشه‌ای مثل `/ai`) آپلود کنید.
2. دسترسی نوشتن پوشهٔ `data` را روی `755` یا `775` بگذارید.
3. در `config.php` مقدار `secret` را عوض کنید.
4. تمام! سایت آماده است. PHP 7.4 به بالا کافی است.

## دربارهٔ خطای 404 در لینک‌های `/s/CODE`

این خطا وقتی رخ می‌داد که `mod_rewrite` یا `.htaccess` فعال نبود. الان:

- فایل `.htaccess` مسیر `…/s/CODE` را به `s.php?c=CODE` می‌فرستد و در زیرپوشه هم (مثل `http://localhost/ai/`) درست کار می‌کند.
- اگر `mod_rewrite` در دسترس نباشد، برنامه خودکار تشخیص می‌دهد و لینک را به شکل `…/s.php?c=CODE` می‌سازد تا همیشه کار کند.
- لینک `…/index.php?c=CODE` هم پشتیبانی می‌شود.

در لوکال‌هاست XAMPP، برای لینک زیبا باید در `httpd.conf` مقدار `AllowOverride` روی `All` باشد و `mod_rewrite` فعال باشد.

### نمونهٔ تنظیم Nginx

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
location ~ ^/s/([A-Za-z0-9_-]{3,32})$ {
    try_files $uri /s.php?c=$1;
}
```

## ساختار پروژه

```
index.php            صفحهٔ اصلی + ساخت لینک
s.php                صفحهٔ نمایش (موس + تایپ + انتقال)
config.php           تنظیمات
lib/helpers.php      توابع کمکی (آدرس پایه، لینک کوتاه، امضا)
lib/store.php        ذخیره‌سازی SQLite / JSON
partials/            قالب مشترک صفحات
assets/              CSS / JS / لوگو
data/                دیتابیس لینک‌ها (محافظت‌شده)
```
